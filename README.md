# Славя-мод. Бесконечное лето

Данный мод поведает историю Бесконечного лета от Лица Слави.\
Разработку мода начал FireBoTer. Данный мод является форком и доработан нами на наше усмотрение.

## Где скачать
Вы можете загрузить мод из [мастерской steam](https://steamcommunity.com/sharedfiles/filedetails/?id=2304057650).\
Или же скачать архивом c [releases](https://github.com/VadimkaG/scenario_slavyana/releases).

## Как установить
Когда вы скачали архив с [releases](https://github.com/VadimkaG/scenario_slavyana/releases) вам необходимо распаковать директорию (папку) scenario_slavyana в game внутри игры.

Например, если у вас игра находится по пути C:\\\steam\steamapps\common\Everlasting Summer\
То у вас должно получиться следущее:
```
C:\\steam\steamapps\common\Everlasting Summer\game\scenario_slavyana
```
